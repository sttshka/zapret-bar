# ZapretBar

Приложение для строки меню macOS, которое одной кнопкой включает обход замедления
и блокировок (YouTube, Discord, X, Instagram и др.). Внутри — `tpws` из проекта
[zapret](https://github.com/bol-van/zapret) с доработкой для macOS: подменой
TLS-приветствия, как у zapret на Windows.

## Скачать

**[ZapretBar.dmg — последняя версия](https://github.com/sttshka/zapret-bar/releases/latest)**
(macOS 13+, Apple Silicon и Intel)

1. Откройте образ и перетащите ZapretBar в «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его
   остановит: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
   Если macOS пишет, что приложение «повреждено»:
   ```bash
   xattr -dr com.apple.quarantine /Applications/ZapretBar.app
   ```
3. В строке меню появится щит. Включите обход и нажмите **«Подобрать»** — приложение
   само найдёт способ, который работает у вашего провайдера.
4. Для Discord, X и сайтов на Cloudflare нажмите **«Разрешить»**: macOS один раз спросит
   пароль администратора (см. «Подмена приветствия» ниже).

## Возможности

- Переключатели сервисов: YouTube, Discord, Instagram/Facebook, X, Rutracker, LinkedIn,
  плюс свои сайты (можно вставлять ссылками) и режим «Все сайты» с исключениями.
- Способы обхода с человеческими описаниями и **автоподбор** под провайдера.
- **«Проверить»** — что открывается, а что блокируется или «замерзает».
- **Диагностика** (Настройки → Диагностика): подробный отчёт, что режет провайдер и
  какой способ помогает. Запускайте без VPN.
- Автозапуск, восстановление состояния, защита от «сломанного интернета» после сбоя.

## Как это работает

- `tpws` запускается от вашего пользователя как SOCKS5-прокси на `127.0.0.1:10888` и
  прописывается в системные настройки прокси (`networksetup`). При выключении и выходе
  настройки сети возвращаются как были.
- Для сайтов из списка `tpws` режет начало TLS/HTTP-соединения, чтобы фильтр провайдера
  (ТСПУ) не узнал имя сайта. Остальные сайты идут как есть.

### Подмена приветствия

Многие провайдеры на разрезы не ведутся: сайт с узнанным именем блокируется, а с
неузнанным — «замораживается» после ~16 КБ (так ведёт себя ТСПУ с Cloudflare). На Windows
и Linux zapret обходит это поддельным ClientHello (`winws`/`nfqws`), но на macOS нет
divert-сокетов, и `nfqws` там не работает.

ZapretBar решает это патчем `patches/tpws-fake-macos.patch`: перед настоящим приветствием
`tpws` пишет в сетевой интерфейс через `/dev/bpf` поддельное — с именем `www.google.com` и
случайными номерами последовательности. Фильтр видит «google.com» и пропускает соединение,
а сервер выбрасывает подделку как пакет вне окна.

Для записи в `/dev/bpf` ставится маленькая системная служба, которая при загрузке отдаёт
`/dev/bpf*` вашему пользователю — так же делает ChmodBPF у Wireshark. Отозвать:
**Настройки → Общее → «Отозвать»**. Учтите: доступ к `/dev/bpf` позволяет программам от
вашего пользователя читать сетевой трафик.

## Ограничения

- Работает для программ, которые используют системный прокси: Safari, Chrome, Discord и
  большинство остальных. В Firefox включите «Использовать системные настройки прокси».
- Только TCP: голосовые звонки (UDP) так не обходятся.
- Если сайт заблокирован по IP-адресу (например, Telegram у многих провайдеров), обход DPI
  не поможет — нужен прокси или VPN.
- Подмена работает только без VPN и только по IPv4.

## Сборка из исходников

Нужны Command Line Tools (`xcode-select --install`).

```bash
scripts/build.sh --install    # собрать и поставить в /Applications
scripts/package.sh            # dmg для Apple Silicon и Intel (нужен полный Xcode)
```

`build.sh` сам скачает zapret нужной версии в `vendor/` и применит патч.
Релизы собирает GitHub Actions (`.github/workflows/release.yml`) при публикации тега `v*`.

Полезное для отладки:
- `scripts/diagnose.sh` — та же диагностика, что в приложении;
- `sudo python3 scripts/fake-test.py discord.com x.com` — проверка вариантов подмены
  напрямую через `/dev/bpf`.
